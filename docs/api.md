# Python API / API Python

`ColumnPlan(name, kind, cutpoints=None)` accepts `numeric` or `categorical`. Names are nonempty ASCII with a 64-byte cap; numeric cutpoints are finite, strictly increasing, within ±1e12, at most 15. Categorical cutpoints must be empty. Constructor iterables are read only to the admission sentinel. `ComparisonPlan(columns)` owns an immutable, name-sorted tuple of 1–16 distinct columns.

`Budget(...)` contains positive integer caps, excluding bool, which may only lower hard limits. Its `max_*` parameters include rows/source fields/selected fields/field-name bytes/cutpoints/string bytes/category union/dictionary entries/retained Arrow bytes/batch rows/projected batch bytes/value visits/KS sweep steps/KS union points/report bytes. `budget.to_dict()` exposes actual values.

`compare_tables(reference, current, plan, budget=Budget())` returns a complete immutable `ComparisonReport` or raises `DriftError`. `error.status` and `error.reason_code` are stable typed outcomes. Operational dependency, allocator and native-environment failures are not rewritten as algorithmic budgets. Both tables must have admitted flat fields, including unselected extras. Arrow dictionary values are checked even when unused. Inputs must not be concurrently mutated.

`report.column(name)` exposes `numeric`, `categorical` and `missingness` records. `ExactFraction` exposes `numerator`, `denominator`, `value` and `to_fraction()`. Numeric metrics contain `ks_distance`, `psi`, `reference_bin_counts`, `current_bin_counts`, fixed cutpoints and half-count smoothing. Categorical metrics expose JSD in bits and cardinalities without category labels. Missingness retains counts/rates from present fields even if distribution kinds disagree. `report.schema` compares all source names and physical/logical types.

`report.to_dict()` returns a fresh dictionary; `to_json_bytes()` returns prevalidated immutable finite JSON. The output budget is checked before a successful comparison returns. `report.work` counts original chunk headers/cells/dictionary entries and mapping visits plus KS union steps. Counts depend on physical chunk representation; distances and substantive counts are invariant to row/field ordering.

`compare_dataframes(reference, current, plan, budget=Budget())` is optional: install `.[pandas]`. It imports pandas only on explicit invocation and accepts trusted DataFrames. Numeric dtypes are NumPy int32/int64/float64 or pandas Int32/Int64/Float64; strings use StringDtype; categorical levels must be strings, at most 128, each at most 256 bytes. Unused levels do not become observed categories. Object/mixed, bool, datetime and arbitrary extension dtypes are unsupported. Conversion can allocate before the core's logical byte checks. There is no public SDK file reader.

Os nomes de tipos/funções e códigos acima são idênticos em português. `compare_tables` exige tabelas Arrow prontas e não modifica entradas. `compare_dataframes` é opcional e restrito a DataFrames confiáveis. Erros operacionais não representam orçamento matemático esgotado. Taxas com denominador zero e distribuições sem valores presentes ficam indisponíveis; nunca viram zero artificial. `to_dict()` produz cópia e `to_json_bytes()` só existe após validação completa do limite de saída.
