# Security

Version 0.1.0 is a bounded development tool for cooperative owned local inputs and interpreters. It does not sandbox malicious Python extensions, guarantee native-parser safety or handle hostile concurrent filesystem mutation. Do not use untrusted extension registries or pickle/joblib inputs; no such loader is provided. Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/martinlofranodeoliveira/tabular-drift-audit/security/advisories/new). General organization information is at [Lofrano Tecnologia](https://lofranotecnologia.com.br).

Ferramenta de desenvolvimento para arquivos e interpretadores cooperativos controlados. Não há garantia universal sobre extensões Python, parsers nativos ou mutação hostil de diretórios. Relate vulnerabilidades pelo canal privado do GitHub acima; não envie dados reais de participantes/clientes como exemplo.
